# offsec-toolkit (superseded)

This repo has been **split into dedicated per-exam repos** — go there for the
current versions:

- **[exp301-toolkit](https://github.com/NelzyKN/exp301-toolkit)** — OSED/EXP-301:
  exam-loop CLI (pattern/offset/badchars/egghunter/encoder/ROP scaffold),
  exploit templates (stack BOF, SEH, DEP/ASLR ROP, format string, ROP decoder),
  WinDbg + mona cheatsheet.
- **[web300-toolkit](https://github.com/NelzyKN/web300-toolkit)** — OSWE/WEB-300:
  request replay, blind + time-based SQLi exfiltrators, source-audit grep
  checklists, exploit skeleton, payload corpus, code-review checklist.

Original tooling only — no exam content. Authorized use: OffSec labs/exams and
infrastructure you own or are permitted to test.

Companion: [OSAI-arsenal](https://github.com/NelzyKN/OSAI-arsenal) (AI-300).
